* Overview
  =ytmusic.el= provides a tiny Emacs interface to fetch YouTube‑Music URLs
  (via a helper Python script) and play them with =mpv= inside a =vterm=
  buffer.  It also maintains an in‑memory playlist that can be written to a
  plain‑text file and fed to =mpv=.

* Dependencies
  - Emacs ≥ 27 (uses =vterm=)
  - =vterm= package
  - =mpv= (command‑line player)
  - python3 3.11+
    
* Installation
** from source (github)
- Clone repo into ~/.emacs.d
- Add this to .emacs
#+begin_src elisp
(add-to-list 'load-path (expand-file-name "~/.emacs.d/ytmusic"))
(require 'ytmusic)    
#+end_src

* Customization
  | Variable                  | Default value        | Description                               |
  |---------------------------+----------------------+-------------------------------------------|
  | ~*ytmusic-path*~          | "~/.emacs.d/ytmusic" | Root directory of the helper scripts.     |
  | ~*ytmusic-playlist-file*~ | "playlist.txt"       | File written by =my/vterm-playlist--run=. |

  You can change them via =M-x customize-group RET ytmusic RET=.
** mpv

you can put playlist_switch.lua in your ~/.config/mpv/scripts/

This will display what song is starting in emacs

** youtube

You will likely run into problems with youtube requiring login, please follow https://github.com/ytdl-org/youtube-dl#how-do-i-pass-cookies-to-youtube-dl to get cookies.txt

you will then need to add to your ~/.config/mpv/mpv.conf

#+begin_src
ytdl-raw-options=cookies=/path/to/cookies.txt
#+end_src


* Primary commands
  | Command                                   | Description                                                                                             |
  |-------------------------------------------+---------------------------------------------------------------------------------------------------------|
  | =M-x ytmusic-get-youtube-recommendations= | Prompt for a song name, run =get_song_url.py= and evaluate its output.                                  |
  | =M-x ytmusic-play=                        | Open (or reuse) a *Music* =vterm= buffer, activate the venv, and start =mpv= with the current playlist. |
  | =C-c p p=                                 | Pause/Play                                                                                             |
